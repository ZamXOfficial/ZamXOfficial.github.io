Как получить скрипт?＋

Открой раздел «Публичный релиз», нажми «Показать скрипт», а затем «Копировать».

Как обновить опубликованный текст?＋

Замени содержимое файла script.txt и отправь изменения в репозиторий. Остальные файлы для обычного обновления скрипта менять не нужно.

Почему скрипт не отображается при открытии файла на компьютере?＋

Страница загружает script.txt отдельным запросом. Для проверки открой сайт через GitHub Pages или локальный веб-сервер, а не двойным нажатием на index.html.

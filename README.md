# PROJECT ZENITH — сайт публикации скрипта

Русскоязычный адаптивный сайт с зелёной неоновой темой, анимированной сферической эмблемой Z и движущимся фоновым оформлением.

## Файлы
- `index.html` — структура страницы и весь текст интерфейса.
- `style.css` — оформление, адаптация для телефонов и CSS-анимации.
- `script.js` — загрузка/копирование текста из `script.txt` и анимированный фон с частицами.
- `script.txt` — публичный текст, который увидят посетители сайта.

## Как заменить опубликованный скрипт
1. Открой `script.txt`.
2. Замени демонстрационные комментарии на текст, который вправе распространять.
3. Сохрани файл и отправь изменения в репозиторий.
4. После публикации посетители смогут получить обновлённый текст на сайте.

Для обычного обновления скрипта остальные файлы менять не нужно.

## Публикация через GitHub Pages
В репозитории выбери **Settings → Pages → Deploy from a branch**, затем ветку `main` и каталог `/(root)`. Главный файл `index.html` должен находиться в корне репозитория.

## Важно
Сайт статический и общедоступный. Любой посетитель может открыть `script.txt` напрямую. Не размещай там пароли, API-ключи, токены, личные данные или содержимое, которое должно оставаться приватным.

Функция загрузки `script.txt` работает при открытии сайта через GitHub Pages или локальный веб-сервер. При открытии `index.html` двойным нажатием браузер может блокировать такой запрос.

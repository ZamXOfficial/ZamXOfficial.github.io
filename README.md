# PROJECT ZENITH — сайт публикации скрипта

Обновлённый тёмный интерфейс с зелёными акцентами. Посетитель нажимает «Показать скрипт», сайт загружает `script.txt`, после чего текст можно скопировать.

## Файлы
- `index.html` — структура и тексты страницы.
- `style.css` — весь дизайн и адаптация под телефон.
- `script.js` — загрузка `script.txt` и копирование.
- `script.txt` — публичный текст, который увидят посетители.

## Как заменить скрипт
1. Открой `script.txt` в любом текстовом редакторе.
2. Удали демонстрационные комментарии и вставь свой текст, который вправе распространять.
3. Сохрани файл рядом с `index.html`.
4. Загрузи обновлённый `script.txt` на хостинг вместе с сайтом.

Остальные файлы менять для обычного обновления текста не нужно.

## Бесплатная публикация через GitHub Pages
1. Создай репозиторий на GitHub и загрузи в его корень все файлы проекта.
2. Открой **Settings → Pages**.
3. В **Build and deployment** выбери **Deploy from a branch**.
4. Укажи ветку `main` и папку `/ (root)`, затем нажми **Save**.
5. Адрес опубликованного сайта появится в разделе Pages.

## Важно
Это статический публичный сайт. Любой посетитель может открыть `script.txt` и прочитать его содержимое. Не используй его для хранения приватного кода, паролей, токенов или иных секретов.

Загрузка файла через `fetch` работает через хостинг или локальный веб-сервер. При открытии `index.html` двойным кликом браузер может блокировать чтение `script.txt`.
